Add-ons

An add-on gives helpers a new tool, such as saving a web page as a file. Someone installs it on the computer that will run it, and an owner then chooses which profiles may use each of its tools. A helper can use nothing that was not granted.

{{with .Extra}} {{if and (not .Cards) (not .Orphans)}}

No add-ons yet

Handloom works fully without them. Add one when a helper needs something it does not have.

On the computer that will run it:

handloom addon add FOLDER

FOLDER is the add-on's own folder. The command shows what the add-on can do and asks you to approve exactly what is in the folder. Once it is approved, the computer reports it and it shows up here, ready for an owner to grant its tools to a profile.
