What the app can and cannot do

It acts as you, with a token of its own. It can see what needs you, the jobs, tasks, agents and metrics, read an agent's terminal, start a job and message an agent.

It cannot accept work, answer an agent's question, close a job or change settings. The hub refuses those for this token, whatever the app is set to do. When something needs your decision, the app tells you and you decide in the Inbox.

The settings

The app runs the handloom program on the machine where the app runs, so install it there first (one file). Then add this, once.{{if not .NewToken}} Make a token above to have it filled in; until then TOKEN stands for it.{{end}}

Claude Code

claude mcp add handloom --env HANDLOOM_HUB={{.Base}} --env HANDLOOM_TOKEN={{if .NewToken}}{{.NewToken}}{{else}}TOKEN{{end}} -- handloom mcp --operator

Claude Desktop

Settings → Developer → Edit config (claude_desktop_config.json), then restart the app.

{ "mcpServers": { "handloom": { "command": "handloom", "args": ["mcp", "--operator"], "env": { "HANDLOOM_HUB": "{{.Base}}", "HANDLOOM_TOKEN": "{{if .NewToken}}{{.NewToken}}{{else}}TOKEN{{end}}" } } } }

Codex

Add to ~/.codex/config.toml.

[mcp_servers.handloom] command = "handloom" args = ["mcp", "--operator"] env = { HANDLOOM_HUB = "{{.Base}}", HANDLOOM_TOKEN = "{{if .NewToken}}{{.NewToken}}{{else}}TOKEN{{end}}" }

Then ask the app something like "what needs me in Handloom?" or "start a job to fix the login bug on GB10 with the lead profile". Treat the token like a password.
