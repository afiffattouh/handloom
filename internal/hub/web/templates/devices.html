Computers

A computer runs the link, which starts your agents and carries their messages to this hub. Computers connect out to the hub; nothing connects in. Each computer belongs to the person who added it, and agents run only on your own computers.

On that computer, run this once. It installs Handloom if it is not there, joins this hub, keeps the link running and checks the computer. This page shows the computer as ready when it is. The token works for {{.TTL}} and is not shown again.

Linux or macOS (Terminal)

{{.JoinCmd}}

Already installed handloom there? Run {{.AltCmd}} instead. The computer needs git and tmux; if they are missing the command offers to install them (it asks first) or shows the exact line.

Windows (PowerShell)

Open PowerShell (not as administrator) and paste this line. Windows 10 (version 2004 or newer) or Windows 11.

{{.WinCmd}}

Handloom runs its agents in Linux, and Windows has Linux built in (WSL). This line checks for WSL (if it is missing it explains the one-time wsl --install, which needs administrator permission and a restart, and you paste the same line again afterwards), installs Handloom inside Linux, joins this hub there, and makes the link start by itself when you sign in. Agent programs such as Claude Code must be installed in the Linux side: handloom doctor there prints the exact line.

What the line does: it downloads the installer, which checks its download against the release's checksums, installs Handloom, joins this hub with the one-time token, keeps the link running and checks the computer. It never uses sudo by itself. Safe to paste again.
