Projects

A project is a name and a shared git repository. Any machine can get its own copy on request, and a job can then start from it without anyone cloning by hand. With no GitHub, Handloom can hold the repository itself. For a repository kept elsewhere, such as GitHub, the code and the git logins stay on the machines: this page keeps only the name, the address and where each machine's copy is, and each machine uses its own login.

Let Handloom hold the code

The simplest way to share code with your team: no GitHub, no keys, no passwords. The hub keeps the repository on its own disk and each machine reaches it with the credential it already has. Machines can add branches and nothing else; you merge finished jobs yourself. Confidential jobs cannot use it, because that code would sit on the hub. The hub's git folder must be part of your backups.

Make it on GitHub

A machine makes a new GitHub repository with the gh tool, under its own login, with a first commit so that jobs have a branch to start from. The machine needs gh installed and gh auth login done. Only a person can do this; agents and AI apps cannot.
