Projects

A project is a name and a shared git repository, usually on GitHub. Any machine can get its own copy on request, and a job can then start from it without anyone cloning by hand. The code and the git logins stay on the machines: this page keeps only the name, the address and where each machine's copy is. Each machine uses its own login, so each person's own access applies.

Attach a repository

For a repository that already exists. Use its web address (https://github.com/owner/name) or its ssh address (git@github.com:owner/name). Do not put a password or a token in it: the machines log in for themselves.

Create a repository

A machine makes a new GitHub repository with the gh tool, under its own login, with a first commit so that jobs have a branch to start from. The machine needs gh installed and gh auth login done. Only a person can do this; agents and AI apps cannot.
