---
name: data-analysis-hygiene
description: Analyse data so the result can be trusted. Use for any quantitative question.
---

1. Write the question before you open the data.
2. Look at the data first: row counts, missing values, duplicates, odd ranges. Report what you cleaned and how.
3. Keep raw data untouched; do every step in a script or query someone can rerun.
4. State the method, the sample and its limits. A small sample is stated as small.
5. Show the number with its denominator. Report uncertainty, not just the point value.
6. Do not claim cause from correlation. Say "associated with".
7. Numbers a client will see need a human check; say which ones and how to re-derive them.
