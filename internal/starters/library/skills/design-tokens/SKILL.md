---
name: design-tokens
description: Define colour, type and spacing as named tokens. Use when starting or cleaning up a UI's look.
---

Define tokens by purpose, not by value: background, foreground, muted, border, primary, destructive, and a few state colours, each for light and dark. One sans font and one mono font, five sizes, a 4px spacing scale. Components read tokens only; a raw hex value in a component is a bug. Write the tokens in one file and show a sample of each component using them.
