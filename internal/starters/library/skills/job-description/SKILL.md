---
name: job-description
description: Write a job description that attracts the right people. Use when drafting a role.
---

Start with the outcome the person will deliver in their first year, then the work, then must-have skills (only what is truly required) and nice-to-haves. State pay range and location or remote terms if known. Use plain words; remove exaggerated requirements and gendered or exclusive language. Describe the team honestly. A human approves before posting.
