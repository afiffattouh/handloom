---
name: small-commits
description: Commit small, describable changes. Use whenever you change code.
---

- One commit, one reason. If the message needs "and", split it.
- Message: a line in the imperative that says what changed and why it matters; a body only if the why is not obvious.
- Never commit generated files, secrets, or unrelated formatting changes.
- Run the project's check before you commit; do not commit a red tree.
