---
name: storyline-first
description: Plan a deck as an argument before making any slide. Use when building a presentation.
---

1. Write the answer as one sentence, then the three or four reasons that support it. That is the storyline.
2. Each slide has one message as its title (a full sentence), and the body proves it.
3. Order by the argument, not by the order you did the work.
4. One chart or one table per slide; label the point you want seen.
5. Write the deck as an outline in text first; ask the lead to confirm the storyline before filling in.
6. Appendix holds the detail; the main deck holds the argument.
