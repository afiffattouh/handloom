---
name: ui-review
description: Review a screen for hierarchy, consistency and clarity. Use when judging or improving a UI.
---

1. Squint test: with colour removed, can you tell what matters most on the page?
2. One accent, used for the one action that matters. Colour otherwise only for state.
3. Spacing from one scale; repeated things (rows, cards) identical in structure.
4. Every state exists: empty, loading, error, disabled.
5. Words: buttons say what happens; errors say what to do.
6. Name the three biggest problems and a concrete fix for each. Do not list twenty.
