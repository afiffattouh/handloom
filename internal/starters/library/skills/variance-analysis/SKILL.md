---
name: variance-analysis
description: Explain the gap between plan and actual. Use when comparing budget and results.
---

1. Compute each variance in amount and percent; mark favourable and unfavourable.
2. Rank by size; explain only the ones that matter (the top few and anything unusual).
3. Split each into volume, price and timing where the data allows; say where it does not.
4. For each explanation give the evidence and mark it as fact or hypothesis.
5. End with what changes the forecast and what to ask the owners.
